# Reporting a security problem

Please do not open a public issue for a security problem.

Report it privately in one of two ways:

- on GitHub: the "Report a vulnerability" button on the
  [Security tab](https://github.com/notbadov/artificial-memory/security/advisories/new) of
  this repository;
- by e-mail: info@artificial-memory.com, with "Security" in the subject.

Say what you found, how to reproduce it and which version it concerns (the output of
`npx artificial-memory status`, or the version of the desktop application). Do not include
access keys or the contents of your memory.

This covers the code in this repository and the service it talks to. Everything else, such as
questions and ordinary bugs, belongs in
[GitHub Issues](https://github.com/notbadov/artificial-memory/issues).
